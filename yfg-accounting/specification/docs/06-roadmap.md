# ۶. فازبندی بر اساس اهمیت و وابستگی

زمان‌ها تخمینی‌اند؛ کیفیت نمونه‌های Excel و وضعیت زیرساخت بر برنامه اثر می‌گذارند.

## فاز صفر — کشف نیاز (P0)
- نمونه‌گیری از هر نرم‌افزار و نسخه.
- تأیید معنای `VCHITMID`، `HdrRef` و کلیدهای دیگر.
- تعیین شرکت/دوره/دامنه، نقش‌ها، نمره‌دهی، وزن و موعد.
- تصمیم درباره سرور، VPN و backup.
**خروجی:** mapping ستون‌ها، نمونه‌های آزمون و تصمیم‌های قطعی. **معیار خروج:** قالب‌های پرتکرار و کلیدها مستند شده باشند.

## فاز یک — هسته امن (P0)
- ورود، نقش‌ها و دسترسی شرکت‌ها.
- شرکت و دوره مالی.
- تسک، تخصیص/انتقال، موعد و تاریخچه.
- ممیزی تغییرات حساس و رابط RTL.
**پذیرش:** کارمند فقط داده مجاز را ببیند؛ تاریخچه انتقال باقی بماند.

## فاز دو — ارسال، مرجع و تصمیم مدیر (P0)
- ارسال فایل با نسخه مستقل.
- مرجع اختیاری و نسخه‌بندی immutable.
- تأیید، ارفاق، بازگشت و لغو.
- نمره، یادداشت عمومی/محرمانه و دلایل اجباری.
- تأیید صریح بدون مرجع.
**پذیرش:** سابقه تغییر نکند؛ یادداشت محرمانه نشت نکند؛ بازگشت و ارفاق بدون دلیل رد شود.

## فاز سه — ورود و تطبیق Excel (P1)
- اعتبارسنجی و نرمال‌سازی.
- hash و تشخیص فایل تکراری.
- تطبیق دقیق با شناسه تأییدشده.
- تطبیق ترکیبی، نامزد جایگزینی و صف بازبینی.
- گزارش اختلاف با نسخه الگوریتم.
**پذیرش:** آزمون برچسب‌خورده و اندازه‌گیری خطا؛ موارد مبهم دستی بررسی شوند.

## فاز چهار — گزارش عملکرد (P1)
- میانگین ساده/وزنی، تعداد و وضعیت تسک‌ها، تأخیر، بازگشت و ارفاق.
- فیلتر شرکت، کارمند و دوره.
- خروجی بدون یادداشت محرمانه.
**پذیرش:** محاسبات با محاسبه مستقل برابر باشند.

## فاز پنج — اتصال‌ها و قابلیت‌های پیشرفته (P2)
- connector مستقل برای هر نرم‌افزار/قالب.
- دریافت خودکار از API رسمی یا مسیر فایل امن در صورت امکان.
- اعلان و تحلیل روند پیشرفته.
**پذیرش:** هر connector آزمون مستقل داشته باشد و شکست آن داده اصلی را تغییر ندهد.

## اولویت اجرا
| اولویت | قابلیت | علت |
|---|---|---|
| P0 | امنیت و ممیزی | حفاظت داده و قابلیت پیگیری |
| P0 | تسک و تاریخچه | ستون فقرات گردش کار |
| P0 | نسخه‌بندی فایل‌ها | جلوگیری از از دست رفتن سابقه |
| P0 | تصمیم، دلیل، نمره و محرمانگی | قواعد حیاتی کسب‌وکار |
| P1 | تطبیق Excel | اتوماسیون پس از شناخت قالب‌ها |
| P1 | گزارش عملکرد | وابسته به داده معتبر |
| P2 | اتصال مستقیم نرم‌افزارها | پیچیدگی و هزینه بیشتر |
| P2 | تحلیل پیشرفته | پس از جمع شدن داده باکیفیت |

## پیشنهاد MVP
فاز صفر، سپس فازهای یک و دو؛ این نسخه حتی بدون تطبیق خودکار، مدیریت تسک و تصمیم مدیر را عملیاتی می‌کند. بعد از تأیید نمونه‌های واقعی، فاز سه آغاز شود.
