# راهنمای نصب و راه‌اندازی YFG Accounting Desk

این راهنما برای نسخهٔ MVP 0.3 است و راه‌اندازی در Windows، استقرار وب در شبکهٔ دفتر و نصب/ساخت نسخهٔ Android را یکجا توضیح می‌دهد. برنامهٔ وب روی سرور اجرا می‌شود؛ Windows و Android به همان دادهٔ مرکزی وصل می‌شوند.

## ۱. پیش‌نیازها

- برای اجرای محلی Windows: Windows 10/11 و Python 3.11 یا 3.12 از python.org با گزینهٔ **Add Python to PATH**.
- برای وب در سرور: Docker Engine و Docker Compose v2، یک نام دامنهٔ داخلی/عمومی، گواهی TLS معتبر و ترجیحاً VPN سازمان.
- برای APK: Android Studio با JDK 17، Android SDK Platform 35 و Build Tools 35.0.0. برنامهٔ Android به نشانی HTTPS سرور نیاز دارد.
- برای کاربران: Edge/Chrome به‌روز در Windows و Chrome به‌روز در Android.

## ۲. دریافت و استخراج

فایل ZIP بسته را در پوشه‌ای محلی استخراج کنید؛ برای مثال `C:\YFG-Accounting`. هنگام به‌روزرسانی، پوشهٔ داده را جایگزین یا پاک نکنید. در اجرای محلی Windows، داده‌ها در `%LOCALAPPDATA%\YFG\AccountingDesk` می‌مانند؛ در Docker، پوشهٔ `data/` کنار پروژه است.

## ۳. نصب و اجرای Windows

1. روی `windows\Install-YFG.ps1` راست‌کلیک و **Run with PowerShell** را انتخاب کنید. این کار برنامه و راهنمای نصب را در `%LOCALAPPDATA%\Programs\YFG Accounting Desk` کپی و میانبر دسکتاپ ایجاد می‌کند.
2. میانبر **YFG Accounting Desk** یا `windows\Run-YFG.bat` را اجرا کنید. اجرای نخست Python environment و وابستگی‌ها را آماده می‌کند و برای دریافت بسته‌های Python به اینترنت نیاز دارد.
3. مرورگر به `http://127.0.0.1:8090` باز می‌شود. در صفحهٔ راه‌اندازی اولیه، نام مدیر، نام کاربری و گذرواژهٔ حداقل ۱۲ نویسه تعیین کنید.
4. مدیر شرکت‌ها و حساب‌های کارمندان را بسازد و دسترسی هر کارمند به شرکت‌ها را تنظیم کند.
5. برای نصب ظاهری مانند برنامه، صفحه را در Edge باز کنید و از دکمهٔ «نصب برنامه» یا منوی مرورگر → **Apps → Install this site as an app** استفاده کنید.

اگر اجرای اسکریپت PowerShell طبق سیاست سازمان بسته است، مدیر IT نصب را انجام دهد؛ اجرای `Run-YFG.bat` راه دیگر شروع همان نسخهٔ محلی است.

## ۴. استقرار وب برای تیم

استقرار مرکزی باعث می‌شود اعضای تیم از یک دیتابیس و فایل‌های مشترک استفاده کنند. روی سرور Linux یا ماشین دارای Docker:

1. ZIP را استخراج و وارد پوشهٔ `YFG-Accounting` شوید.
2. اجرا کنید:

   ```bash
   docker compose up -d --build
   ```

3. سرویس به طور پیش‌فرض فقط روی `127.0.0.1:8090` در دسترس است. مدیر شبکه آن را پشت پراکسی معکوس با HTTPS و ترجیحاً VPN قرار دهد؛ پورت 8090 را مستقیم به اینترنت عمومی باز نکنید.
4. کاربران نشانی HTTPS را در مرورگر باز کنند. در Windows از گزینهٔ نصب برنامهٔ Edge/Chrome، و در Android از نصب PWA در Chrome استفاده کنند.
5. برای تغییر یا ارتقا کد، نسخهٔ جدید را مستقر کنید و پوشهٔ `data/` را حفظ کنید. پس از ارتقا، ورود، بارگذاری یک فایل آزمایشی و مشاهدهٔ گزارش را بررسی کنید.

برای آزمایش روی همان رایانه می‌توان از Windows installer استفاده کرد. حالت محلی روی `127.0.0.1` برای چند دستگاه یا استفادهٔ بیرون از رایانه مناسب نیست. همگام‌سازی داده بین اجرای محلی Windows و سرور وب خودکار نیست.

## ۵. نصب روی Android بدون APK (پیشنهادی برای استفادهٔ عادی)

این روش وب‌اپ را از سرور امن اجرا می‌کند و نیازی به انتشار APK ندارد:

1. در گوشی، Chrome را به شبکهٔ امن شرکت/VPN وصل کنید.
2. نشانی HTTPS سامانه را باز و وارد حساب کاربری شوید.
3. منوی سه‌نقطه → **Install app** یا **Add to Home screen** را بزنید و تأیید کنید.
4. آیکن YFG Desk در صفحهٔ اصلی ظاهر می‌شود. برای خروج از حساب از خود سامانه استفاده کنید.

نصب PWA تنها روی دامنهٔ HTTPS قابل اتکا است؛ `localhost` رایانه در گوشی به خود گوشی اشاره می‌کند و سرور Windows را نشان نمی‌دهد.

## ۶. ساخت APK اندروید با Android Studio

پروژهٔ Android داخل `android/` یک پوستهٔ سبک WebView است که به سرور مرکزی وصل می‌شود. آدرس سرور باید HTTPS باشد و از گوشی قابل دسترسی باشد.

1. ابتدا بخش ۴ را اجرا و نشانی HTTPS نهایی را آماده کنید؛ برای نمونه `https://accounting.example.org`.
2. Android Studio را نصب کنید، Android SDK Platform 35 و JDK 17 را از SDK Manager نصب کنید.
3. در Android Studio، **Open** را بزنید و پوشهٔ `android/` را انتخاب کنید. Gradle Sync را کامل کنید.
4. پیش از ساخت، نشانی HTTPS واقعی را در خط `YFG_WEB_URL` فایل `android/gradle.properties` قرار دهید (علامت `#` ابتدای خط را بردارید). یا متغیر محیطی `YFG_WEB_URL` را تنظیم و Android Studio را از همان محیط باز کنید. مثال در PowerShell:

   ```powershell
   $env:YFG_WEB_URL = 'https://accounting.example.org'
   ```

   در Linux/macOS:

   ```bash
   export YFG_WEB_URL=https://accounting.example.org
   ```

5. در Android Studio از **Build → Build APK(s)** استفاده کنید. برای فایل انتشار، **Build → Generate Signed Bundle / APK → APK** را انتخاب و کلید امضای سازمان را نگهداری امن کنید.
6. APK آزمایشی معمولاً در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. برای نسخهٔ نهایی از APK امضاشده استفاده کنید و نصب را روی گوشی آزمایشی بررسی کنید.
7. هنگام انتشار نسخهٔ تازه، `versionCode` و `versionName` را در `android/app/build.gradle` افزایش دهید. APK به‌تنهایی داده نگه نمی‌دارد؛ داده در سرور است.

پوستهٔ Android فقط اتصال امن HTTPS به همان دامنه را داخل برنامه نگه می‌دارد؛ پیوندهای بیرونی را در مرورگر باز می‌کند و HTTP ناامن را نمی‌پذیرد. برای استفاده در شبکهٔ خصوصی، VPN گوشی و گواهی TLS معتبر روی سرور لازم است. برای ساخت این APK، یک URL سازمانی واقعی باید در `YFG_WEB_URL` قرار گیرد.

## ۷. قالب Excel، حساب‌ها و حریم خصوصی

قالب Excel را از داخل جزئیات تسک دریافت کنید. مدیر باید شرکت‌ها و کاربران را تعریف کند و دسترسی‌ها را بازبینی کند. برای هر کارمند حساب جداگانه بسازید و نقش مدیر را محدود نگه دارید. یادداشت محرمانه فقط برای نقش‌های مجاز است. برای این MVP، راه‌اندازی MFA و اتصال مستقیم به دیتابیس حسابداری در نظر گرفته نشده است.

ثبت عملکرد در منوی مستقل «ثبت عملکرد» انجام می‌شود و از گزارش Excel داخل هر تسک جداست. کاربر تاریخ شمسی، نوع کار، عنوان، شرح و زمان صرف‌شده را ثبت می‌کند. مدیر/مدیرعامل گزارش‌های تیم را می‌بیند و می‌تواند آن‌ها را تأیید یا برای اصلاح برگرداند؛ کاربر گزارش برگشتی را ویرایش می‌کند. «گزارش عملکرد تیم» نیز خلاصهٔ امتیازها و وضعیت تسک‌ها را جداگانه نشان می‌دهد.

## ۸. پشتیبان‌گیری و بازیابی

- Windows محلی: `%LOCALAPPDATA%\YFG\AccountingDesk`
- Docker: پوشهٔ `data/` در کنار `compose.yaml` (داخل کانتینر `/data`)

هنگام توقف سرویس، از کل پوشهٔ داده شامل دیتابیس و فایل‌های بارگذاری‌شده نسخهٔ پشتیبان رمزنگاری‌شده بگیرید. پشتیبان را در فضای محدود و امن نگهداری کنید و بازیابی را دوره‌ای در محیط آزمایشی امتحان کنید. قبل از ارتقای نسخه نیز پشتیبان تازه بگیرید.

## ۹. رفع اشکال سریع

- **صفحه در Windows باز نمی‌شود:** Python نصب باشد؛ `Run-YFG.bat` را از پوشهٔ نصب اجرا و پیام خطا را بررسی کنید. پورت 8090 نباید توسط برنامهٔ دیگری اشغال باشد.
- **گوشی به سامانه وصل نمی‌شود:** VPN، اینترنت، گواهی TLS و دسترسی گوشی به دامنهٔ سرور را بررسی کنید. `127.0.0.1` را به عنوان نشانی سرور گوشی وارد نکنید.
- **APK پیغام نشانی سرور می‌دهد:** `YFG_WEB_URL` را با URL کامل HTTPS تنظیم کنید و Gradle Sync/Build را دوباره انجام دهید.
- **تغییرات وب روی گوشی دیده نمی‌شود:** Chrome را کامل ببندید و باز کنید، یا دادهٔ سایت را پاک و PWA را دوباره نصب کنید.
- **ورود در گوشی باقی نمی‌ماند:** مطمئن شوید دامنه HTTPS ثابت است و سرویس پشت پراکسی، هدرهای forwarded را درست تنظیم می‌کند.
