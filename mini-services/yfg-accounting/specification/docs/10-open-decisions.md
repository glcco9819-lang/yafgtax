# ۱۰. تصمیم‌های باز

| موضوع | پیشنهاد اولیه |
|---|---|
| محل اجرا | سرور محلی دفتر |
| دسترسی بیرونی | VPN + MFA |
| نمره تسک تکمیل‌شده | اجباری |
| وزن اهمیت | عادی ۱، مهم ۲، خیلی مهم ۳ |
| گزارش عملکرد | نمایش میانگین ساده و وزنی |
| موعد اصلاح | اختیاری؛ دلیل بازگشت اجباری |
| ارفاق | دلیل اجباری |
| تطبیق | پیشنهاد سیستمی؛ تصمیم نهایی با مدیر |
| آستانه شباهت | بعد از آزمون داده واقعی تعیین شود |
| نگهداری فایل | نسخه‌بندی بدون overwrite |
| حذف رویداد/تصمیم | در عملیات عادی ممنوع |
| RPO/RTO | پیشنهاد اولیه ۲۴ ساعت/یک روز کاری |
| سیستم‌عامل و سرور | پس از بررسی زیرساخت دفتر |
| تقویم تاریخ | مشخص‌کردن قواعد دقیق تقویم دفتر |
| نرم‌افزار نمونه | نام و نسخه باید مشخص شود |

## چک‌لیست فاز صفر
1. فهرست نرم‌افزارها و نسخه‌ها.
2. ۲ تا ۵ فایل نمونه از هر قالب، با پوشاندن داده حساس در صورت نیاز.
3. تعریف کار کامل‌شده برای انواع رایج تسک.
4. نگاشت دسترسی هر کارمند به شرکت‌ها.
5. سیاست نمره‌دهی و وزن‌ها.
6. سیاست backup و نگهداری فایل.
7. تعداد کاربران هم‌زمان و مشخصات سرور.
8. تأیید معنای شناسه‌هایی مانند `VCHITMID` و `HdrRef`.
