# سامانه مدیریت وظایف دفتر حسابداری — بسته مستندات v1.0

این بسته نقشه راه محصول و فنی برای سامانه داخلی مدیریت تسک، گزارش کار، تطبیق Excel و ارزیابی عملکرد است؛ **خودِ نرم‌افزار اجرایی در این بسته پیاده‌سازی نشده است**.

## زمینه
- حدود ۵۰ شرکت و ۵ کارمند.
- نرم‌افزارهای حسابداری متنوع؛ نسخه اول با فایل Excel کار می‌کند و اتصال مستقیم به نرم‌افزارها را به فاز بعد می‌سپارد.
- فایل مرجع مدیر اختیاری است.
- فایل‌ها، داده خام و پایگاه داده روی سرور محلی دفتر نگهداری می‌شوند؛ دسترسی بیرونی از VPN امن و ترجیحاً MFA.
- هر نسخه مرجع، فایل ارسالی، نتیجه تطبیق و تصمیم مدیر باید تاریخچه مستقل داشته باشد.

## فایل‌ها
1. `docs/01-requirements.md` نیازمندی‌ها و قواعد کسب‌وکار
2. `docs/02-architecture.md` معماری و فناوری
3. `docs/03-data-model.md` مدل داده و جداول
4. `docs/04-reconciliation.md` الگوریتم تطبیق Excel
5. `docs/05-workflow-scoring.md` گردش کار، تصمیم‌ها و ارزیابی
6. `docs/06-roadmap.md` فازبندی بر اساس اهمیت
7. `docs/07-security-operations.md` امنیت و عملیات
8. `docs/08-api.md` طرح API
9. `docs/09-testing.md` طرح آزمون
10. `docs/10-open-decisions.md` تصمیم‌های باز
11. `templates/` نمونه CSV برای ورود تسک و آزمون تطبیق
12. `architecture.mmd` نمودار معماری Mermaid

**اصل راهبردی:** تطبیق خودکار باید قابل توضیح باشد. اختلاف یا شباهت احتمالی به‌تنهایی دلیل خطای قطعی کارمند یا کسر خودکار امتیاز نیست.
